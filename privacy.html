개인정보처리방침

shorts-studio는 개발자 본인만 사용하는 로컬 프로그램입니다.

사용하는 정보

Google 계정 로그인으로 YouTube 업로드 권한(youtube.upload)만 요청하며, 사용자가 만든 영상을 사용자 본인 채널에 올리는 데에만 씁니다.

TikTok 계정 로그인으로 영상 업로드 권한(video.upload)만 요청하며, 사용자가 만든 영상을 사용자 본인 TikTok 계정에 초안으로 보내는 데에만 씁니다. 게시는 사용자가 TikTok 앱에서 직접 합니다.

저장과 공유

로그인 토큰은 사용자 컴퓨터에만 저장되며 외부 서버로 보내거나 제3자와 공유하지 않습니다. 토큰 파일을 지우거나 Google 계정 설정(https://myaccount.google.com/permissions) 또는 TikTok 앱 설정에서 권한을 취소할 수 있습니다.

참고

이 프로그램은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관, Google 개인정보처리방침

이 프로그램은 TikTok Content Posting API를 사용합니다. TikTok 서비스 약관, TikTok 개인정보처리방침
